# 歌曲与玩家编配版本页

从乐谱搜索结果点击“开始练习”，只在原页面上弹出歌曲信息与版本列表这一内容面板，不带详情页导航栏和上方横幅，也不改变搜索 URL。关闭按钮、Escape 可关闭浮层；搜索词、筛选和滚动状态保留。手机浮层内部滚动时关闭按钮保持可见。

点击封面或“预览”仍可打开独立歌曲详情，例如 `/static/classroom/#song?id=sunny`。返回按钮保留进入前的搜索词；搜索页组件保持挂载，避免丢失本次页面中的收藏状态。

## 视觉与源码

- 参考图：`classroom/design-reference/song-detail.jpg`；可见区域：`song-detail-visible.png`。
- 页面及路由：`classroom/src/SongDetail.jsx`。
- 样式：`classroom/src/song-detail.css`。
- 独立素材与完整逐图提示词：`classroom/public/assets/song-detail/`，最终使用清单见 `manifest.json`。
- 所有新增位图通过内置 `image_gen` 一张一张生成，没有拼图、精灵图或整页截图背景。品牌、通用图标与已有页面素材沿用原项目资源。

参考图为 1448 × 1086，但可用页面画面到 y=697，以下是黑色区域。还原与视觉对照以完整的 1448 × 697 可见区域为准，没有把黑色区域实现为网页内容。在 1448px 视口下，顶部导航为 48px，第一排版本卡片从 y=478 到 y=697。

## 已接通的页面交互

歌曲入口、返回搜索、8 个编配演示版本、乐器/星级/谱种/调性筛选、四种排序、版本收藏、谱例弹窗、速度调节、练习音色试听、Escape 关闭，以及详情侧栏切换。

讨论回复只保留在当前页面。编配作者、评分、练习人数和版本内容均为演示数据；谱例图片为独立生成的视觉素材，不是完整原曲乐谱。试听是用于检查交互的练习音色演示，不是原曲录音。以上范围已在页面或谱例弹窗中标明。

## 验证

- 1448px 桌面可见区域全图与重点卡片区域并排对照。
- 390px 手机、768px 平板和正常桌面视口检查。
- 搜索结果 → 晴天详情 → 返回原搜索结果 → 稻香详情。
- 吉他筛选得到 4 个版本；叠加四星后为 1 个；再选五线谱进入空状态；清空恢复 8 个。
- 最新发布排序、收藏、谱例打开、85 BPM 调节、试听与暂停、Escape 关闭均通过。
- 详情页浏览器 warning/error 日志为空。

截图与对比图在 `docs/classroom/qa/song-detail-*`、`detail-comparison-*` 和 `detail-focused-final.jpg`；最新视觉报告在仓库根目录 `design-qa.md`。

补充浮层验证：同一搜索 URL 下弹出单个内容面板，没有重复页头/横幅；关闭后吉他筛选及 4 条结果保留。嵌套谱面第一次 Escape 只关闭内层，第二次关闭版本浮层；关闭后页面滚动恢复。390px 下浮层范围 y=12–832，内部滚动 1146px 后关闭按钮仍可见。截图：`song-detail-overlay.jpg`、`song-detail-overlay-mobile.jpg`。
